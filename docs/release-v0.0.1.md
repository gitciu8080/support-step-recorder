## v0.0.1 中文增强版

基于 Le-Syl21/support-step-recorder 的首个增强版本，保留上游历史与授权声明。

- 增加简体中文界面、报告文案与内嵌中文字体。
- 增加无损截图和原尺寸查看；修复截图队列满时丢图，提升 Wayland 请求帧率。
- Linux Wayland 启动时选择录制窗口或屏幕，后续录制复用选择。
- Linux Fcitx5/AT-SPI 记录中文提交及字段变化，减少导出为拼音的问题。
- 可配置视觉模型，在录制后分析截图、生成步骤描述，并支持人工修改。

### 下载

Windows 64 位：下载并解压 `ssr-v0.0.1-windows-x86_64.zip`，运行 `ssr.exe`。SHA256 校验值在附带的 `.sha256` 文件中。

### 当前限制

Windows 二进制由 GitHub Actions 编译并运行自动测试，尚未进行 Windows 实机录制验收；程序未签名。启动选区与中文输入修复目前主要适用于 Linux Wayland，Windows 沿用前台窗口截图，中文输入法记录仍需后续适配。高速操作的实际截图帧率取决于桌面环境，持续超负载可能造成处理延迟。

视觉服务需自行配置，本版本不包含本机模型密钥或录制数据。
